# 📝 LeetCode Solutions

This folder contains **LeetCode problem solutions** in multiple languages.  
Contributors can add solutions for problems from [LeetCode](https://leetcode.com/) following the guidelines below.

---

## 📂 Folder Structure

Solutions should be organized as follows based on the language branch:

cpp/LeetCode/<Problem_Name>.cpp
java/LeetCode/<Problem_Name>.java
python/LeetCode/<Problem_Name>.py

Copy code

> ⚠️ Ensure that your **commit and PR target the correct language branch**.  
> 💡 If the branch for a language doesn’t exist, create a new branch with the language name.

---
